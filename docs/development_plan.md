## Rebuild sequence

To update the external intelligence and regenerate dependent project artifacts, run these commands from the repository root:

```powershell
python src/objective1_enrichment.py --refresh-intelligence
python src/risk_engine.py
python src/prioritization_engine.py
python src/train_models.py
python src/generate_visualizations.py
python src/verify_objective1.py
```

NVD rate limits may make the refresh take several minutes. The local web app reads generated files; it does not refresh sources or retrain on page load.
